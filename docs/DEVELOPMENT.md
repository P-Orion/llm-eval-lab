# Development and ownership
This is an independent personal portfolio project, developed with AI coding assistance. It does not contain employer code, private datasets, or unpublished BrainBench material. Dataset preparation, actual training/inference, tests, and recorded results are separated from product claims.
For an interview walkthrough, run the project locally, change one component, and explain the documented tradeoffs. Regenerate measured reports after any model/scorer change; never replace results with aspirational numbers.
Use Python 3.11 and Node 22 or newer. The Python install is editable because artifact/data paths belong to the checkout. Container homes are explicitly set. Lock files record the environment; upstream data and model notices retain their own licenses.
